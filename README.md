## Quick start

```bash
git clone [https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-44.git](https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-44.git)
cd moekyawaung-developer-portfolio-44

npm run dev
```
