# Contributing

Thank you for helping improve this professional portfolio. Small, focused changes are preferred.

## Ground rules

1. Open an issue before large design or architecture changes.
2. Keep the cyberpunk / cryogenic visual language consistent.
3. Do not commit secrets, `.env` files, or personal documents.
4. Follow existing TypeScript / Tailwind / component patterns.
5. Test on mobile and desktop before opening a PR.
