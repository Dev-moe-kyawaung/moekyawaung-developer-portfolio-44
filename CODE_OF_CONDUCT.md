# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/) Code of Conduct, version 2.1.

## Our pledge

We pledge to make participation in this portfolio and its community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, experience level, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Our standards

**Expected**

- Respectful, professional language
- Constructive feedback on code, design, and documentation
- Credit for others’ work
- Focus on what is best for users and the project

**Unacceptable**

- Harassment, insults, or personal attacks
- Sexualized language or imagery
- Doxxing or publishing private information
- Trolling, spam, or derailing reviews
- Any conduct that would be inappropriate in a professional setting

## Enforcement

Report issues to **moekyawaung@programmer.net** with:

- What happened
- Where it happened (issue, PR, discussion, email)
- Dates and relevant links

The maintainer will review reports promptly, keep reporter privacy, and may warn, restrict, or ban contributors.

## Scope

This Code applies in the GitHub repository, issues, pull requests, discussions, and any official project space.
